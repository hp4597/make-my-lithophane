# Make My Lithophane

A local Windows desktop studio for turning photos into printable lithophanes. Photos remain on the device; no account or service is required.

Version **0.3.0** adds a batch CLI. See [CLI.md](CLI.md) for folder processing, saved profiles, JSON results, overwrite protection, and the bundled `lithophane-cli.cmd` launcher.

## Run and build

Requires Node.js 22.12 or newer and npm.

```powershell
npm install
npm start
```

### One-click Windows distribution build

Double-click **`build-distribution.bat`**. It installs locked dependencies, runs geometry/export tests, and builds both executables in `release/`:

- **`Make My Lithophane 0.3.0 Portable.exe`** — run the app without installing; no Node.js required on the destination computer.
- **`Make My Lithophane Setup 0.3.0.exe`** — Windows installer with installation-folder selection and desktop shortcut.
- **`win-unpacked/Make My Lithophane.exe`** — unpacked app; keep all files in that folder together.

For a terminal or CI run without a final keypress: `build-distribution.bat --no-pause`. Internet is needed for build dependencies, but the resulting app works offline. The script respects an existing `NODE_EXTRA_CA_CERTS`; otherwise it exports Windows' public trusted certificates into a temporary PEM for Node, without disabling TLS verification or changing machine settings.

`npm test` runs geometry checks. `npm run package` produces both installer and portable executable. `npm run package:dir` produces only the unpacked application. `npm run dev` opens a development server at the URL printed by Vite.

## Workflow

1. Import a PNG, JPEG or WebP, or drag it onto the app.
2. Choose a shape and dimensions in millimeters. Sphere/cylinder dimensions use the **inner** diameter; thickness increases the outer diameter.
3. Adjust image fit, zoom, position, rotation, mirror, brightness, contrast, gamma, inversion or caption.
4. Inspect solid, illustrative backlit, or wireframe preview.
5. Export a binary STL, or a ZIP kit containing STL, a self-contained project and printing notes. Light-box kits also include a separate enclosure. Flat color-paper kits contain a 1:1 SVG backing.
6. Open the STL in your slicer; verify scale, orientation, islands, supports, and print settings before printing.

Save/open `.litho` project files to retain the original image and all settings. Ctrl+S saves a project. Resolution controls export sample spacing; the preview is deliberately coarser. PLA mass is based on solid geometry at 1.24 g/cm³, excluding supports and brim.

## Scope and parity

This is an independent implementation, **not complete or verified feature parity** with Lithophane Maker Desktop. The reference feature families were researched from [American Filament's official product page](https://americanfilament.us/products/lithophane-maker-desktop) on September 29, 2026. Its public feature summary does not fully specify every desktop setting or algorithm.

| Feature family | Current implementation | Remaining work |
| --- | --- | --- |
| Flat / curved | Closed thickness mesh, border, curvature, hanging holes | Integrated interchangeable mounts |
| Cylinder / lamp | Wrapped closed shell, taper, wavy perimeter, separate ring/spoke adapters | Hardware-specific tested fittings |
| Sphere / moon | Closed top, bottom opening, procedural relief | Lunar image map, lamp sockets |
| Heart / silhouette | Heart mask, brightness threshold | Smoother contour extraction, island management |
| Night light | Curved panel and separate parametric U-channel adapter | Hardware-specific fit testing |
| Light box | Panel/enclosure; four-photo walls, base, assembled 3MF | Snap fit and cable routing |
| Color lithophane | Physical-size color-paper SVG; experimental CMYW STL/3MF volumes | Measured filament-specific calibration |
| Filament painting | **Work in progress — disabled and paused at user request** | Resume only when explicitly requested |
| Photo editing | Fit/crop, zoom/pan, rotate, mirror, tone, hue, saturation, caption, multi-photo grid/panorama | Interactive crop handles, per-photo layout edits |
| Preview / export | Orbit, zoom, backlit approximation, mesh, PNG, binary STL, 3MF, ZIP | Calibrated light simulation |
| Projects | Self-contained save/open, IndexedDB recovery autosave, libraries, batch panel export | Recent-project browser |
| Mounting parts | Separate slotted stands, U-channel clips, rings, four-spoke lamp adapters | Tested mechanical fit and integrated attachments |

No proprietary assets, code, branding or licenses are included. A procedural sample landscape is generated by the application. No physical print validation has been performed.

## Architecture

- Electron: sandboxed renderer, context isolation, narrow IPC for native save dialogs.
- Vite and plain JavaScript UI; Three.js for 3D preview.
- Canvas image processing, background worker for mesh creation and binary STL encoding.
- Indexed front/back surfaces with joined borders and welded periodic seams/poles.
- Node's test runner checks topology, orientation, physical thickness, STL encoding and invalid input.

## Known constraints

- Silhouette thresholding bridges point-only contacts by one sample cell. Use the largest-connected-shape option to remove detached islands. Inspect fine bridges in your slicer.
- Large models at fine spacing use substantial memory; export has a cell budget and never silently reduces requested detail.
- Moon texture is procedural. Backlit mode is a visualization, not a filament-calibrated physical simulation.
- Unsigned local installers may trigger Windows' unknown-publisher prompt.

## Advanced studios

**Photo library & layouts:** Add up to eight images, reorder or remove them, choose a grid/panorama and gap brightness. Individual panel export makes a numbered STL for each photo. Four-sided light boxes use the first four photos and include a base and assembled 3MF for placement reference. Print walls separately and assemble with adhesive; the open top admits an LED puck.

**Filament painting:** Work in progress. Its experimental implementation is preserved but disabled for version one. Development must remain paused until the user explicitly asks to continue.

**CMYW mode:** Generates four closed, adjacent color volumes and a multipart 3MF, with one layer minimum per channel. The separation estimates optical density and quantizes channel depth to layer height. Slicers may require explicit extruder assignments. This experimental output needs physical calibration; it is not a reproduction of a commercial filament palette.

**Hardware workshop:** Parametric generic adapters export STL and 3MF with dimensions. Parts are separate, not automatically fused to the photo mesh. Measure hardware and test tolerances. Sphere/lamp rings and spider adapters require retention or adhesive.

**Recovery:** Edits trigger a local IndexedDB autosave after a short delay. Use Restore local autosave to recover it. Saving a `.litho` file remains the portable backup workflow. Project files include the photo library, color studio and mount settings.

Run `npm run test:desktop` for the Electron/Playwright workflow suite. It exercises real renderer-to-main-process save IPC while substituting only the native file dialog in the test process.

## Version 0.3: matching supports and color backlighting

Width and height in the Model tab resize the panel. **Matching support: Auto** includes a stand for flat, curved and night-light panels, a fitted case for light-box panels, and no support for other shapes. Select None for panel-only exports. Stand slots follow maximum thickness plus clearance per side; the case cavity follows panel width and height. Support walls, fit clearance, print spacing and case depth are adjustable. The preview shows the assembled fit; STL and 3MF exports arrange separate parts side by side at Z=0. Kits also contain separate part STLs and `print-layout.3mf`. Check the combined footprint and orientation in your slicer. The case has an open front and a ledge, without a snap retainer; secure the panel with removable adhesive or your own retainer. Fit and stability need a physical test print.

CMYW kits include a matching support sized from actual combined material thickness, plus a layout 3MF preserving channel alignment. The CLI accepts `--support auto|none|stand|case`, `--fit-clearance`, `--support-wall` and `--print-gap`; its default Auto includes matching supports in batch exports.

**Backlit** works on all ten shapes in monochrome and color-paper modes. Paper colors follow the edited photo and surface mapping; printable backing sheets remain limited to flat panels. The **CMYW studio** opens with a predicted backlit color image and updates it when layer height or color depth changes. Kits include `predicted.png`. These are illustrative optical previews, not calibrated filament predictions. CMYW geometry remains flat. Filament painting remains disabled and paused.
